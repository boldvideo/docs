## Quick taste

```bash
curl "https://app.boldvideo.io/api/v1/videos" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Get an API key under [Settings → Developer](https://app.boldvideo.io/settings/developer), then explore the [API docs](/api).
